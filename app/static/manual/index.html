はじめに VC長さ計算 コイル 平板

はじめに

紙管に巻かれた VCフィルムの残りの長さと定尺ごとの枚数・早見表(VC長さ計算)と、コイル・平板の重量・長さ・巻き数(3D の図・グラフ・計算書の印刷)を1つの画面で使うツールです。日報管理ツールの「VC長さ計算」の面をそのまま移したもので、VC計算マスタも同じファイルを共有できます。

  • 開き方
  • 画面のつくり(5つの面)
  • 2つの版は同時に使えない
  • 終わり方
  • 版の見方
  • 困ったとき

開き方

ふだんはデスクトップ版を使います。デスクトップ版が使えないときだけ、予備のブラウザ版を使います。計算の中身と結果はどちらも同じです。

版開き方閉じ方
デスクトップ版(ふだん)CoilCalculator.exe をダブルクリック窓の右上の × →「終了する」
ブラウザ版(予備)Start.vbs をダブルクリック。既定のブラウザ(Edge など)で開きます画面の右上の「終了」→ OK
要るものこのPCに Python(3.8 以上)が入っていれば動きます。追加のインストールはありません。インターネットにつながっていなくても使えます。

画面のつくり

上の面の札で、5つの面を切り替えます。右上は版・操作説明書・背景(ライト / ダーク)の切替です。それぞれの面の使い方は、次の頁にあります。

面すること説明
計算品種を選び、肉厚を入れて「計算」。VC長さと定尺ごとの枚数、図と計算の経過VC長さ計算
早見表肉厚 → 長さの表(計算と同じ式)。A4 横で印刷。別の窓でも開けますVC長さ計算
コイル・平板コイル・平板の重量・長さ・巻き数。真ん中でコイルと平板を切り替えますコイル / 平板
設定VC計算マスタの置き場所・早見表の品種を足す/消す・管理者パスワード(管理者)VC長さ計算
マスタの表VC計算マスタの表を見る・1行ずつ直す(管理者)VC長さ計算

画面の右上の「操作説明」を押すと、いま見ている面(VC長さ計算・コイル・平板)の説明書が開きます。デスクトップ版では別の窓、ブラウザ版では別のタブで開きます。

2つの版は同時に使えない

デスクトップ版とブラウザ版は、同時には動きません。後から開いたほうが、理由を知らせて止まります。先に開いているほうはそのまま使えます。

先に開いている後から開いたどうなるか
ブラウザ版デスクトップ版「ブラウザ版が動いています」と出て、デスクトップ版は開きません
デスクトップ版ブラウザ版「デスクトップ版が開いています」と出て、ブラウザ版は開きません
デスクトップ版デスクトップ版新しくは開かず、開いている窓が前に出ます
ブラウザ版ブラウザ版新しくは開かず、動いている画面がブラウザで開きます
デスクトップ版に切り替えたいときブラウザ版の画面の右上の「終了」を押してから、デスクトップ版を開きます。ブラウザのタブを閉じただけのときは、1〜2分たつとブラウザ版が自分で終わるので、それから開けます。

終わり方

デスクトップ版

窓の右上の × を押すと、「終了しますか?」と確かめが出ます。「終了する」を押すと閉じます(計算の処理も一緒に終わります)。「やめる」を押すと、そのまま使い続けられます。

業務ツール統合ランチャーで別のツールに切り替えたときは、確かめを出さずに閉じることがあります(ランチャーの設定によります。書いている最中なら書き終えてから閉じます)。

説明書の窓・早見表の窓が開いていても、計算の窓を閉じれば全部終わります。説明書・早見表の窓の × は、確かめずにその窓だけを閉じます。VC計算マスタへ書いている最中に終了を押すと、確かめの文に「書いている最中です」と出ます。少し待ってから終了してください。

ブラウザ版

画面の右上の「終了」を押し、「ブラウザ版を終了しますか?」で OK を押します。キャンセルなら、そのまま使い続けられます。終わったら、ブラウザのタブを閉じてください。

止まらないときは、ツールのフォルダの stop.bat をダブルクリックします(デスクトップ版も、これで確かめ無しに閉じます)。

版の見方

画面の右上に、いま使っている版と、デスクトップ版かブラウザ版かが出ています。押すと詳しい中身が出ます。不具合を知らせるときは、この版を一緒に伝えてください。

項目意味
アプリこのツールの版です。説明書の上の「この説明書の版」と同じなら、この説明書がそのまま当てはまります
動き方デスクトップ版か、ブラウザ版か
外枠(Rust)デスクトップ版の窓を出している部分の版です(デスクトップ版のときだけ)
計算(Python)このPCに入っている Python の版です

印刷した計算書のいちばん下にも、印刷したときの版が入ります。デスクトップ版の窓の題名(いちばん上の帯)にも版が出ます。

困ったとき

こうなったこうする
デスクトップ版を開くと「起動できませんでした」と出る出ている理由と「次にすること」に従います。多いのは Python が入っていないときです(下の図)。直るまではブラウザ版も同じ理由で使えないので、担当に連絡してください
計算の面の上に「マスタを読めないので、最後に読めた中身で…」「VBA に直書きされていた初期値で…」と出るVC計算マスタの置き場所(共有のフォルダ)に届いていません。計算はそのまま使えます(最後に読めた中身か VBA の初期値)。共有がつながれば次の操作で戻ります。置き場所が違うときは「設定」→ マスタの置き場所 で直します(設定)
「マスタの表」や「設定」で直そうとすると「管理者パスワードが要ります」と出る管理者パスワードを入れて「鍵を開ける」を押します。終了するか「鍵を閉める」まで開いています(鍵)
入力した欄が赤くなり、結果が変わらないその欄の値が範囲の外です。欄の下に出ている範囲の中の値に直すと、すぐ計算されます(コイル / 平板)
画面の上に赤い帯「計算の処理(Python)と繋がりません」が出るツールを閉じて開き直します。ブラウザ版なら Start.vbs をもう一度開きます
「印刷」が押せない範囲の外の欄(赤い欄)があると印刷できません。直してから押してください
3D の図のところに「3D表示を使えません」と出るこのPCの設定で 3D の機能が止められています。計算・グラフ・印刷はそのまま使えます
ブラウザ版が開かないstart.bat をダブルクリックすると、原因が黒い画面に出ます

ログ(動作の記録)の場所: %LOCALAPPDATA%\CoilCalculator\logs\coilcalc.log
