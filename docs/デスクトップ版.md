# デスクトップ版(Tauri)の作り

専用の窓(`CoilCalculator.exe`)で動きます。**ポートを使いません。**
ブラウザ版(`Start.vbs`)は予備として残してあります。土台は
[python-web-tools](https://github.com/ViVio-Hellon/python-web-tools)(梱包資材総合ツール)の
デスクトップ版と同じで、このツールに合わせて次を変えています。

| | python-web-tools | このツール | 理由 |
|---|---|---|---|
| 画面のファイル | Python が返す | **Rust がディスクから返す** | 画面は静的なファイルだけ。three.js(600KB)を標準入出力に通さない |
| Python に渡すもの | すべての要求 | `/api/…`(計算)だけ | 同上 |
| Python の部品 | Flask + waitress | **標準ライブラリだけ** | ラインPCに追加のパッケージを入れられない。経路が数本なので振り分けは表で足りる |
| 起動の合言葉 | あり | なし | 標準入出力は親子だけの通り道で、こちらの Python はほかに口を持たない |
| ブラウザ版との関係 | — | **同時に動かさない(後から開いたほうが止まる)** | 依頼による |

## 要求の流れ

```
窓(WebView2)
  │  app://localhost/…(Windows は http://app.localhost/…)── ネットワークを通らない
  ▼
外枠(Rust)main.rs::handle
  ├─ /api/… ──▶ bridge.rs ──標準入力──▶ bridge.py ──▶ coilcalc.web.App.handle ──▶ calc.py / vc_api.py
  │                         ◀─標準出力──
  └─ それ以外 ──▶ static_files.rs(app/static/ の中だけ。`..` は通さない)
```

ブラウザ版は同じ `coilcalc.web.App.handle` を `http.server` から呼びます。
**計算・範囲・丸め・表示の文字は、どちらの版でも同じ関数を通ります。**

## 終わり方(「終了」と窓の × は同じ確かめ)

確かめの文と「止めてよいか」の判断は **Python の1か所**(`coilcalc/web.py` の `QUIT_CONFIRM` と `/api/shutdown`)。

```
窓の ×(Rust)/ ブラウザ版の「終了」(JS)
   │ POST /api/shutdown {}                ← 確かめ無し
   ▼
Python: 止めずに 409 {"confirm": {"message": "…終了しますか?", "yes": "終了する", "no": "やめる"}}
   │ 利用者に見せる(Rust はダイアログ、JS は confirm)
   ├─ 「やめる」・閉じた → 何もしない(動いたまま)
   └─ 「終了する」 → POST /api/shutdown {"confirmed": true} → Python が止まる(デスクトップ版は quit を知らせて exe も終わる)
```

- `confirmed` が `true` 以外("yes"・1・無し)では**止まらない**(`tests/test_web.py`)。勝手に「はい」にならない
- Python が動いていない(起動できなかった・落ちた)ときは、訊く相手がいないので × でそのまま閉じる
- `stop.bat`(業務ツール統合ランチャーが切り替えのときに使う)は確かめを出さずに止める。
  ブラウザ版へは `POST /api/shutdown {"force": false}`、デスクトップ版へは錠の隣の `stop.request`
  (ポートが無いので。錠を握っている exe の pid 宛て。`coilcalc/stop_request.py`)。
  VC計算マスタへ書いている最中なら書き終えてから止まる(docs/ランチャー連携.md)。
  ランチャー 1.7.0 は `launcher_stop.bat`(中身は stop.bat と同じ)を使い、`launcher_check.bat` で止まったことを確かめる
- 試験では `COIL_TOOL_CLOSE_ANSWER=yes|no` で答えを決める。**決めていなければ必ず確かめを出す**。
  `scripts/desktop_smoke.py` が本物の × を送り、「やめる」で動いたまま・「終了する」で Python ごと終わることを確かめる

## ブラウザ版との排他

```
%LOCALAPPDATA%\CoilCalculator\runtime\instance.lock   OS のファイルロック
%LOCALAPPDATA%\CoilCalculator\runtime\instance.json   いま握っているのは誰か(版・pid・URL)
```

- デスクトップ版(Rust `instance.rs`)は `LockFileEx`(ファイル全体)、ブラウザ版(Python
  `instance_lock.py`)は `msvcrt.locking`(先頭1バイト)。範囲が重なるので互いに取れない
- 錠を取れなかった側が `instance.json` を読んで、誰が動いているかを知らせて止まる
- 錠は OS が持つので、落ちても残らない(次に開いたほうが取れる)
- 作業フォルダの決め方は Rust と Python で同じ(`tests/test_instance_lock.py` が突き合わせる)
- 試験(`COIL_TOOL_QUIET=1`)ではダイアログを出さずに終了コード 3 で終わる
- **作業フォルダが壊れていても起動を止めない。** 錠を置く場所は「作業フォルダ → 一時フォルダ(TEMP → TMP → OS の既定)」
  の順に試す(Rust・Python で同じ順)。「誰かが握っている」と「この場所が使えない」を分け、使えなければ次へ進む。
  どちらも使えなければ排他無しで起動する(計算だけの道具で、2つ動いても壊れるデータが無い)。
  持ち主の印(instance.json)が書けない・壊れているときも止めない

## 画面の組み立て(2.0.0 から)

```
index.html(外の枠: 見出し・面の札・VC長さ計算)          vc/*.js(ES モジュール)・vc/vc.css
  └─ 「コイル・平板」の面 ── <iframe src="coil/index.html">   開いたときに読み込む(3D とグラフは大きい)
```

- 枠の中のコイル・平板は、見出しの部品(版・操作説明・終了・背景)を外の枠に任せる(`html.is-framed`)
- 背景(ライト / ダーク)は同じ所に覚え、片方で選ぶともう片方も付いていく(`storage` の知らせ)
- CSP の `frame-ancestors` は `'self'`(同じ所の枠にだけ載る。よその画面には載らない)。Rust と Python で同じ
- 「早見表を別の窓で開く」は外枠の `open_quick` が窓 `quick`(`index.html?window=quick&tab=quick`)を開く。
  ブラウザ版は `window.open`。この窓の × は確かめずにその窓だけ閉じる

## 読んだファイルを掴まない

このツールが読むアプリのフォルダのファイルは、設定・画面のファイル・Python のファイル。
どれも**読むたびに開いて閉じる**(Rust は `std::fs::read`、Python は `read_bytes` / `read_text`)。
**共有の VC計算マスタは、手元(`%LOCALAPPDATA%\CoilCalculator\cache\source`)に写してから開く**
(`coilcalc/source_db.py`。作業フォルダが使えなければ一時フォルダ)。書くときだけ元を開き、1つの取引で閉じる。
Windows では開いたままのファイルは差し替えられないので、動いている間に差し替えられることを試験で確かめる
(`tests/test_file_handles.py`、`tests/test_vc_shared_master.py`、`scripts/desktop_smoke.py` の 7・9。Windows の CI で流す)。
動いている間に差し替えられないのは、実行中の `CoilCalculator.exe` 自身だけ(OS の決まり。exe を替えるときは閉じてから)。

## 動きの約束

| 場面 | 動き |
|---|---|
| 起動 | 窓がすぐ出る(画面のファイルは Rust が返す)。計算は Python の受け付けが始まりしだい |
| もう1つ起動しようとした | 新しく起動せず、開いている窓を前に出す(single-instance。使えない環境でも錠で止める) |
| ブラウザ版が動いている | 「ブラウザ版が動いています」を出して終わる |
| Python が見つからない・起動できない | 理由と次にすること(Python の入れ方)・ログの場所を窓に出す |
| Python が途中で落ちた | 窓を読み直して理由の画面を出す |
| 窓の × | **ブラウザ版の「終了」と同じ確かめを通る**(下の「終わり方」)。「終了する」で終わる。標準入力が閉じるので Python も終わる(取り残さない)。操作説明書の窓が開いていても全部終わる |
| 印刷 | 画面の「印刷」→ WebView2 の印刷ダイアログ(計算書は画面と同じ文字) |
| 操作説明 | 画面の「操作説明」→ 外枠の `open_manual` が別の窓(`manual`)で説明書を開く。開いていればその頁へ移して前に出す。開ける頁は `index` `vc` `coil` `plate` だけ |
| 早見表を別の窓で | 外枠の `open_quick` が窓 `quick` を開く(開いていれば前に出す) |
| VC計算マスタへ書いている最中に × | 確かめの文に「書いている最中です」が足される |
| 版 | 窓の題名に「v2.3.0」。画面の版の詳細に外枠の版(応答の見出し `X-Coil-Shell-Version`)・Python の版(`/api/health`) |

画面から外枠に頼めるのは `open_manual` と `open_quick` だけです(`capabilities/default.json`。画面は `app://` で返す
ファイルなので `remote` に宛先を書く。python-web-tools と同じ形)。

Python は**同梱しません**。各PCに入っている Python を使います(`python.exe` → `py.exe -3` の順に探す。
`COIL_TOOL_PYTHON` で指定もできる)。追加のパッケージは要りません。

## 作り方

**Windows 版は GitHub Actions が作ります**(`.github/workflows/desktop-windows.yml`)。
push のたびに Python の試験(Windows・Python 3.8)・Rust の試験・exe の作成・exe を起動しての確認まで流れ、
成果物 `CoilCalculator-windows` に `CoilCalculator.exe` が入ります。
配るときは exe をアプリのフォルダの**直下**(`bridge.py` と同じ場所)に置きます。

手元で作るとき(開発機):

```
cd src-tauri
cargo build --release            # target/release/CoilCalculator(.exe)
python ../scripts/desktop_smoke.py --exe target/release/CoilCalculator    # Linux は xvfb-run を前に付ける
```

Linux で作るには WebKitGTK が要ります(`libwebkit2gtk-4.1-dev` など)。Rust は 1.89 以上。

## 置き場所の決まり

- exe は `bridge.py` と同じフォルダに置く(上の階層もたどるので、`src-tauri/target/...` から動かしても見つかる)。
  `COIL_TOOL_ROOT` で指定もできる
- 版は `config/app.json`・`src-tauri/tauri.conf.json`・`src-tauri/Cargo.toml` の3か所。食い違うと試験が落ちる
- アイコンは `scripts/make_desktop_icon.py` で作る(標準ライブラリだけ。`src-tauri/icons/`)

## 確かめきれていないこと(Windows の実機で見る)

窓を実際に動かした確認は Linux(WebKitGTK)で行いました。Windows では GitHub Actions が
「起動して計算が返る・待ち受けない・止めたら Python も終わる・ブラウザ版との排他(両方向)」まで確かめます。
次は**実機で人が見る**必要があります:

- 「印刷」から実際に紙が出ること(WebView2 の印刷ダイアログ)
- ラインPCで 3D(WebGL)が出ること(出ない PC では、元どおり「3D表示を使えません」と出て計算とグラフは使える)
- ブラウザ版が開いているときにデスクトップ版を開いたダイアログの見え方
- 共有フォルダ(\\サーバ\共有)に置いた VC計算マスタを、2台から同時に直したときの待ち(SQLite の鍵。試験は同じPCの2接続で確かめた)
- 早見表の印刷(A4 横)が紙に収まること
