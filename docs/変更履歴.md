# 変更履歴

版は `config/app.json`・`src-tauri/tauri.conf.json`・`src-tauri/Cargo.toml` の3か所(試験が突き合わせる)。

## 1.1.0

- **版の表示**: 画面の左上に版と「デスクトップ版 / ブラウザ版」。押すとアプリ・外枠(Rust)・計算(Python)の版。
  デスクトップ版の窓の題名・印刷した計算書のいちばん下にも版
- **操作説明書**: 画面の写真入りの HTML(`app/static/manual/`。はじめに・コイル・平板)。
  画面の左上の「操作説明」で、いま見ている形状の頁が開く(デスクトップ版は別の窓、ブラウザ版は別のタブ)
- 写真は `scripts/make_manual_images.py` で撮り直せる(ブラウザ版は Playwright、デスクトップ版は本物の窓を xdotool で操作して撮る)
- デスクトップ版: 計算の窓を閉じたら、操作説明書の窓が開いていてもアプリ全体が終わる(Python と錠を残さない)

## 1.0.0

- 日報管理ツールの「VC長さ計算 → コイル・平板」を単体のアプリとして移植。
  デスクトップ版(Rust/Tauri・ポート無し)とブラウザ版(予備)。計算は Python(標準ライブラリだけ)。
  ブラウザ版とデスクトップ版は同時に動かない(後から開いたほうが止まる)
