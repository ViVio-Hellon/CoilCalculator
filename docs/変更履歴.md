## 2.3.0

- **配布: 配った先で押すとショートカットを作る `scripts\make_shortcuts.vbs`**(python-web-tools の同じ名前のファイルと同じ作り)
  - 配った先の PC で `scripts\make_shortcuts.vbs` をダブルクリックすると、ツールのフォルダ(scripts の1つ上)に
    - `VC長さ・コイル平板 計算ツール(ブラウザ版).lnk` … Start.vbs
    - `VC長さ・コイル平板 計算ツール(デスクトップ版).lnk` … CoilCalculator.exe(アイコンも exe のもの)
    を作る。指す先・作業フォルダは**押したときの**フォルダ。何度押しても作り直すだけ。フォルダを移したら押し直す
  - exe が入っていないフォルダでは、デスクトップ版のショートカットは作らず、そのことを結果の窓で知らせる
  - Windows の機能(WSH)だけで動く(Python も追加のライブラリも要らない)。CP932・CRLF
  - 名前は文字の番号(Unicode)から組み立てる(.vbs はシステムの文字コードで読まれるので、日本語をそのまま
    書くと日本語でない Windows で名前が化ける。python-web-tools の CI で実際に化けた)
  - make_dist は scripts のうち**これだけ**を配布フォルダの `scripts\` に入れる(ほかが入っていたら作るのをやめる)。
    配布メモ・説明書(はじめに)に、配った先ですることとして書いた
  - 置き場所を scripts にしたのは、ツールの直下の .vbs・.bat はランチャーが起動ファイル・入口として読むため
  - ショートカットの中身(指す先・作業フォルダ・アイコン)は **Shell.Application** で書く。WScript.Shell の
    ショートカットはシステムの文字コードで名前と場所を扱うので、その文字コードに無い文字があると保存できない
    (英語の Windows の CI で実際に「Unable to save shortcut」)。一時フォルダに英字の名前で作って本来の場所へ写し、
    Unicode で扱える Shell.Application で書き直す。保存できなかったときは理由を結果の窓に出し、終了コード 1
- 確かめたこと: 試験(CP932・CRLF・BOM なし、名前を文字の番号から戻すと表示名・(ブラウザ版)・(デスクトップ版)になる、
  .lnk の名前に日本語を直接書かない、押したときの場所から求める、配布フォルダに入るのはこれだけ、配布メモに出る)。
  Windows では本当に cscript で押して、exe が無いと1つ・置くと2つ・押し直しても作り直すだけ・指す先が押したときの
  フォルダであることを見る。CI では、exe 入りの配布フォルダでも押して2つできることを見る

    exe の行にもポートを入れ、デスクトップ版を /api/health で待って「起動できませんでした」になる
  - 試験: `tests/test_launcher.py`(ランチャー本体のコードで登録の読み取り・起動確認・停止)・
