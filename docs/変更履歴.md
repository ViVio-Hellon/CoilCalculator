## 2.1.0

- **業務ツール統合ランチャー(python-business-tools-launcher)との連携**(docs/ランチャー連携.md):
  - `stop.bat` が**デスクトップ版も**止める(確かめ無し)。ポートが無いので、錠の隣の `stop.request` で
    exe の pid 宛てに頼む(`coilcalc/stop_request.py`)。VC計算マスタへ書いている最中なら書き終えてから止まる。
    `--force` で待たずに止める。戻り値 0 = 止まった、1 = 止まらなかった
  - `/api/health` にランチャーが見るもの(`app_id`・`ready`・`stage`・`pid`・`port`・`app_root`)を足した
  - `/api/shutdown {"force": false|true}`(ランチャーの停止要求)を受ける。確かめは求めない。
    書き込み中は `409 {"reason": "busy", "running": [...]}`。画面の「終了」・窓の × は今までどおり確かめる
  - `Start.vbs` が引数を渡す(ランチャーが渡す `--no-browser` を落とさない。落とすと画面が2枚開く)
  - アプリID を `nlm.coil-calculator` に(兄弟のツールと同じ付け方)
  - `config/app.json` に `server.port` を書かない(既定の 8741 はプログラムの中)。書いてあると、ランチャーが
    exe の行にもポートを入れ、デスクトップ版を /api/health で待って「起動できませんでした」になる
  - 試験: `tests/test_launcher.py`(ランチャー本体のコードで登録の読み取り・起動確認・停止)・
    `test_launch_windows.py`(Start.vbs に引数が届く)・`desktop_smoke.py` の 10(stop.bat で exe が確かめ無しに終わる)。
    Windows の CI はランチャーを取ってきて流す

- 配布: `make_dist.bat --admin-password`(撹拌して入れる)。`start.bat --check` が VC の部品も確かめる

- デスクトップ版: 最初の面が VC長さ計算になったので、起動の確認(desktop_smoke)は VC の答えで見る。
  動いている間に VC計算マスタを差し替えられることも確かめる

### 2.0.0 の総点検で直したもの(配る前の点検。版はそのまま)

- マスタの表: 1行保存すると、鍵が開いたままなのに「見るだけ」の表示に戻っていた(書いたあとの答えに鍵の状態が無かった)
- マスタの表: 保存・追加・削除のたびに並び替えが元に戻っていた
- マスタの表: 面を開いた直後に表を選び替えると、先に頼んだ表の返事で選んだ表が戻ることがあった
- マスタの表: 表を替えても前の誤りの文が残っていた / アプリ設定で「足す・消すはできない」理由が出ていなかった
- 書くボタンを二度押ししても、返事が来るまでは送らない
- **コイル・平板を切り替えると画面が揺れ続けた**のを直した。画面に収める仕組み(coil-fit)が、
  カード・入力欄の余白が 0.3 秒かけて変わる途中の高さをはかっていて、枠の高さがある幅
  (デスクトップ版の窓でちょうど当たる)に入ると「そのまま」と「詰める」を毎コマ行き来していた。
  はかる間は動きを止め、行き来が続いたら詰めた側に決めて止める歯止めも付けた
- デスクトップ版の起動直後に「早見表を別の窓で開く」を押しても、外枠に窓を頼む
- 早見表の注意書きの案内先を「マスタの表」の面に
- 試験: 日報管理ツールの実物のコードと同じマスタを読み書きし合う試験(`tests/test_vc_interop.py`。
  日報管理ツールのリポジトリが手元にあるときだけ流す)・上の不具合が戻らない試験

## 1.2.0

- **窓の × に確かめ**: デスクトップ版の窓の × が、ブラウザ版の「終了」と同じ確かめ(「終了する」/「やめる」)を通る。
  確かめの文と判断は Python の1か所。`/api/shutdown` は `{"confirmed": true}` のときだけ止まる(確かめ無しでは止まらない)
- **作業フォルダが壊れていても起動する**: 錠を一時フォルダに置いて続ける(排他は保つ)。どこにも置けなければ排他無しで起動。
  以前は、デスクトップ版が「もう一方の版が動いています」と取り違えて止まり、ブラウザ版も「起動できません」で止まっていた
- 読んだファイルを掴まないことを試験で確かめる(動いている間に設定・画面・.py を差し替えられる。Windows の CI で流す)
- 操作説明書: 「終わり方」に × の確かめを追記。写真を撮り直し
