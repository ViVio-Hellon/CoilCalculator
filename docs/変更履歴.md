# 変更履歴

版は `config/app.json`・`src-tauri/tauri.conf.json`・`src-tauri/Cargo.toml` の3か所(試験が突き合わせる)。

## 2.0.0

- **VC長さ計算を一緒に移植**(日報管理ツールの「VC長さ計算」の面をまるごと。コイル・平板とセット):
  計算(VC長さ・定尺ごとの枚数・逆算・図と計算の経過)/ 早見表(A4 横の印刷・早見表だけの窓)/
  設定(マスタの置き場所・早見表の品種を足す/消す/式⇔固定値・管理者パスワード)/
  **マスタの表**(VC計算マスタを1行ずつ直す。日報管理ツールの マスタ管理 →「VC計算マスタ」に当たる)。
  名前を「VC長さ・コイル平板 計算ツール」に。コイル・平板は外の枠の面に載る(単独でも開ける)
- **VC計算マスタ**(sqlite3。日報管理ツール・vc-calculator と同じ表の形・同じファイルを共有できる):
  写してから読む(共有を掴まない)・差し替えに付いていく・書く/変更履歴/更新番号を1つの取引で・日ごとの控え・
  壊れていても控えか VBA の初期値で計算を続ける。置き場所は 端末の設定 → 配布の既定 → 作業フォルダ の順
- 計算の式・丸めは日報管理ツールと同じ(試験 `test_vc_*.py`・`test_web_vc.py` を写して流す)
- 配布: `make_dist.bat --admin-password`(撹拌して入れる)。`start.bat --check` が VC の部品も確かめる
- 版・操作説明・終了は右上に。操作説明書に「VC長さ計算」の頁を足し、写真を撮り直し
- デスクトップ版: 最初の面が VC長さ計算になったので、起動の確認(desktop_smoke)は VC の答えで見る。
  動いている間に VC計算マスタを差し替えられることも確かめる

## 1.2.0 の追補(版は上げずに直したもの)

- **start.bat が起動しなかった**のを直した(`if (...)` の塊の中の半角 `)` で cmd.exe が塊を閉じていた)。
  Windows の CI で start.bat / Start.vbs / stop.bat を本当に動かして確かめる
- **配布フォルダを作る仕組み** `scripts/make_dist.bat`(配るものだけを写す・起動ファイルは CP932 + CRLF を保証・
  exe とマスタの置き場所を入れる)。GitHub Actions の成果物 `CoilCalculator-dist`

## 1.2.0

- **窓の × に確かめ**: デスクトップ版の窓の × が、ブラウザ版の「終了」と同じ確かめ(「終了する」/「やめる」)を通る。
  確かめの文と判断は Python の1か所。`/api/shutdown` は `{"confirmed": true}` のときだけ止まる(確かめ無しでは止まらない)
- **作業フォルダが壊れていても起動する**: 錠を一時フォルダに置いて続ける(排他は保つ)。どこにも置けなければ排他無しで起動。
  以前は、デスクトップ版が「もう一方の版が動いています」と取り違えて止まり、ブラウザ版も「起動できません」で止まっていた
- 読んだファイルを掴まないことを試験で確かめる(動いている間に設定・画面・.py を差し替えられる。Windows の CI で流す)
- 操作説明書: 「終わり方」に × の確かめを追記。写真を撮り直し

## 1.1.0
