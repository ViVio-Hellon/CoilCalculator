# 移植と機能維持の確認(移す前に確かめたこと)

対象: 日報管理ツール `vba-daily-report-python-migration` の「VC長さ計算 → コイル・平板」
(`app/static/vc/coil/` 一式。確認した版: コミット `4df0c24`)。
**この部分だけ**を取り出し、Python + Tauri/Rust のデスクトップ版にしました。

## 1. 移す前に分かったこと(結論に効く事実)

| 事実 | 意味 |
|---|---|
| コイル・平板の**計算はすべて画面の JS** だった(`aluminum-coil-calculator.js` ほか)。Flask 側にコイル・平板の業務処理は**無い** | 「Flask の処理を移す」というより、**Flask は画面のファイルを配るだけ**だった。移すのは「配る役」と、JS にあった計算 |
| 日報管理ツールには iframe で載っていた(`vc.html`)。外側との繋がりは「テーマの同期」と「枠の高さ合わせ」だけ | 単体のアプリにすると、この2つは**持ち主がいなくなる**(外側が無い)。中の道具は自分のテーマ切替・画面合わせを持っているので困らない |
| 中身はデータを保存しない・DB に触らない・外部ファイルを読まない | DB(sqlite3 / ACE)の移行は**不要** |
| ライブラリ(three.js・Chart.js・Font Awesome)は同梱済み・CSP は `script-src 'self'` | そのまま持ってこられる。デスクトップ版でも同じ CSP を付ける |
| Python 側の依存: 日報管理ツールは Flask + waitress | 新しいツールは**標準ライブラリだけ**にできる(経路が数本しかない) |

**結論: 現在の機能はすべて維持できる。** 妨げになるものは見つかりませんでした。
変える点は §3 の通りで、どれも「元の不具合に近い振る舞いを、平板と同じ動きに揃える」か「新しく足すもの」です。

### 「文字まで同じ」をどう保証したか

計算を JS から Python に移すと、次の違いで**画面の数字が1桁ずれる**おそれがあります。すべて JS に合わせました
(`coilcalc/jsnum.py`)。

| 違い | JS | Python の標準 | 対応 |
|---|---|---|---|
| 0.5 ちょうどの丸め | `(2.5).toFixed(0)` = "3" | `f"{2.5:.0f}"` = "2"(偶数側) | 2進の値そのものを 0 から遠い側へ丸める |
| 整数の書き方 | `${400}` = "400" | `str(400.0)` = "400.0" | JS の Number→文字の規則を写す |
| 四捨五入(巻き数) | `Math.round(2.5)` = 3 | `round(2.5)` = 2(偶数側) | `Math.round` を写す |
| 0 で割る | `0/0` = NaN(画面に「NaN m」) | 例外で止まる | JS と同じく NaN / Infinity を返す |
| 欄の文字の読み方 | `parseFloat("12abc")` = 12 | `float("12abc")` は例外 | `parseFloat` を写す |
| 計算の順序 | `π × r² × 幅` を左から | 同じ式でも順序を変えると最後の桁が変わる | JS と同じ順に書く |

元の JS を node で動かす試験(`tests/test_js_equivalence.py`)が、境目の値・丸めの分かれ目・乱数の約 3,000 組で
**完全一致**を確かめます。わざと Python の標準の丸めに戻すと 73 組が食い違うことも確かめ、試験が本当に
違いを見つけられることを確認しました。

## 3. 変える点(意図した差分)

| 点 | 元(日報管理ツール) | 新 | 理由 |
|---|---|---|---|
| 計算する場所 | 画面の JS | Python(`coilcalc/calc.py`) | 正を1か所に。デスクトップ版・ブラウザ版が同じ計算を通る。試験が標準ライブラリだけで書ける |
| コイル: ほかの欄が範囲外のとき | 打った欄だけを確かめ、**ほかの欄が範囲外・空でも計算**して「NaN kg」などを出すことがあった | 範囲外の欄が1つでもあれば計算せず、結果は前のまま(**平板と同じ動き**) | 元の平板の作りに揃えた。範囲内の値の結果は1文字も変わらない |
| コイル: グラフの線 | 軸を選び直したときだけ線を作り、ほかの欄を変えても**線が古いまま**(現在値の印だけ動く) | 計算のたびに線を描き直す(**平板と同じ動き**) | 同上 |
| 開いた瞬間の見本の数字 | HTML に古い見本(4,066.3 kg など。実際の計算と違う)。JS がすぐ上書き | 「—」。最初の計算が返りしだい置く | 計算が非同期になったので、違う数字が一瞬見えないように |
| 計算書の下の名前 | 「VCフィルム長さ計算 ─ コイル・平板」 | 「コイル・平板 重量計算ツール」 | 単体のアプリになったため |
| ブラウザ版の「終了」・繋がらないときの帯・タブを閉じたら自動で終わる | — | 新しく足した | ブラウザ版が残ると、デスクトップ版が開けないため |

## 4. ポート

- **デスクトップ版はポートを使いません**(`scripts/desktop_smoke.py` が、exe・Python・WebView の
  どのプロセスも待ち受けていないことを確かめる)
